A desktop expense management system built using Java Swing.

This project focuses on making a traditional desktop app feel smarter and more interactive using lightweight AI-style logic.

No frameworks.  
No databases.  
Just Java, logic, and UI.

---

## 🧠 Core Features

- 💸 Add and manage expenses
- 🤖 Auto detect expense categories
- 📊 Predict average spending
- 📈 Analyze spending behavior
- ⚡ Live expense updates
- 🖥 Interactive Swing interface



## 🛠 AI Features

ExpenseAI automatically categorizes expenses using keyword analysis.

```java
pizza   -> Food
uber    -> Traveling
netflix -> Entertainment
pubg    -> Gaming
```

It also predicts spending patterns based on user history.

```java
prediction = totalExpenses / numberOfExpenses;
```

## 🚀 Running The Project

Compile:

```bash
javac ExpenseAI.java
```

Run:

```bash
java ExpenseAI
```
